1.Create a trigger to handle inserts to the product relation ( if price < 25000 the set price to 50000).

mysql> create trigger product_price before insert on PRODUCT for each row begin if new.price<25000 then set new.price=50000; end if; end//
Query OK, 0 rows affected (0.00 sec)
