1.Create a function to calculate price_range(low, medium, high) of each product. If price<=35000
indicate as low, upto 60000 indicate as medium, and above as high.

mysql> CREATE FUNCTION price_ranges(p INT) RETURNS VARCHAR(10) DETERMINISTIC BEGIN DECLARE price_category VARCHAR(10); IF p <= 35000 THEN SET price_category='low'; ELSEIF p<=60000 THEN SET price_category='MEDIUM'; ELSE SET price_category='high'; END IF; RETURN price_category; END//
Query OK, 0 rows affected (0.00 sec)
