2. Write a MongoDB query to count number of customers in each city. 
3. Write a MongoDB query to find minimum and maximum age in each city. 
4. Write a MongoDB query using the $match stage to retrieve all customer documents whose
   customer_name starts with the letter “S”.
5. Write a query using $lookup to join CUSTOMER and PRODUCT collections and display only
   customer name, product name, and price.

2.INVOICE> db.customer.aggregate([{$group: { _id: "$city", total_customers: { $sum: 1 }}}]) 
[
  { _id: 'tvm', total_customers: 1 },
  { _id: 'mlp', total_customers: 1 },

]

3.INVOICE> db.customer.aggregate([{$group: { _id: "$city",min_age: { $min: "$age" },max_age: { $max: "$age" }}}])

  { _id: 'mlp', min_age: 21, max_age: 21 },
  { _id: 'tvm', min_age: 23, max_age: 23 },
